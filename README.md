

## Cardápio Online
Este é um sistema de cardápio online moderno e responsivo, ideal para restaurantes e lanchonetes que desejam digitalizar seu menu. Os clientes podem navegar pelos pratos, ver detalhes e preços de forma intuitiva.

O projeto foi construído utilizando as tecnologias mais recentes do ecossistema JavaScript, oferecendo uma experiência de usuário rápida e fluida.
First, run the development server:

- [Next.js](https://nextjs.org/): Framework de React para renderização do lado do servidor e geração de sites estáticos.
- [TypeScript](https://www.typescriptlang.org/): Superconjunto tipado do JavaScript que adiciona segurança e escalabilidade ao código.
- [Tailwind CSS](https://tailwindcss.com/): Framework CSS utilitário para construir interfaces de usuário rapidamente.
- [Shadcn UI](https://ui.shadcn.com/): Biblioteca de componentes reutilizáveis e acessíveis para React.


- Visualização de Cardápio: Exibe categorias e pratos de forma organizada.
- Detalhes do Prato: Permite clicar em um item para ver a descrição completa, ingredientes e preço.
- Busca Rápida: Funcionalidade de pesquisa para encontrar pratos facilmente.
- Design Responsivo: Layout otimizado para dispositivos móveis, tablets e desktops.

### Pré-requisitos

Certifique-se de ter as seguintes ferramentas instaladas:

- [Node.js](https://nodejs.org/en/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

### Executando o Projeto

Siga os passos abaixo para rodar o projeto na sua máquina:

1.  Clone o repositório:
   
    git clone [https://github.com/seu-usuario/seu-projeto.git](https://github.com/LEBEATO)./foodylanches.git)
    
    
2.  Instale as dependências:
   
    npm install
    # ou
    yarn install
    
3.  Execute o servidor de desenvolvimento:
   
    npm run dev
    # ou
    yarn dev
    
O projeto estará disponível em http://localhost:3000.
